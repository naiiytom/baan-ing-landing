## Reporting a Vulnerability

We take the security and privacy of the **BAAN/ING** platform and our users seriously. If you discover a security vulnerability or sensitive data exposure, please follow our responsible disclosure guidelines.

### How to Report

- **Email**: Send a detailed report to [security@baan.ing](mailto:security@baan.ing).
- **Include**:
  - Description of the vulnerability.
  - Steps to reproduce or proof-of-concept.
  - Potential impact and affected components.
- **Response Time**: Our security team will acknowledge receipt of your vulnerability report within **48 hours** and provide periodic updates on the status of the fix.

Please do **not** open public GitHub issues for security vulnerabilities.

## Data Privacy & PDPA Compliance

BAAN/ING complies with the **Thailand Personal Data Protection Act (PDPA B.E. 2562)**:
- Lead capture and waitlist data are encrypted in transit via TLS 1.3 and at rest with AES-256 isolation.
- No analytics trackers or invasive third-party telemetry scripts are executed without explicit user consent.
- For data subject access requests or deletion requests, contact [privacy@baan.ing](mailto:privacy@baan.ing).
